## Project context

USC Football needed a structured analytical foundation for turning provider data into repeatable analysis and dashboarding. The work centers on designing and implementing a data warehouse that ingests PFF API data and prepares it for decision support.

## Data and architecture

The project uses dbt, SQL, Python, Azure, and Databricks to move from source data to analysis-ready models. The architecture separates ingestion, transformation, and presentation concerns so that football analysis can build on consistent definitions rather than one-off extracts.

## My contribution

I work with USC Football stakeholders to shape the warehouse around useful analytical questions, implement pipelines, and organize data for downstream dashboards. The role combines analytics engineering with the domain context required to make the resulting models useful to decision-makers.

## Current status

This is ongoing work. The page documents the project structure and verified scope without publishing private team data, internal dashboards, or conclusions that are not cleared for public release.

## Limitations

The underlying data and team environment are not public. Public examples should use synthetic or approved aggregates, and any findings should be reviewed before publication.
