## Project context

The apparatus project combined electrical engineering, image processing, and control-system planning. The analytical task was to turn recorded image sequences into particle-position information that could support controlled tweezer manipulation.

## Computer vision workflow

I worked with MATLAB and Python image-processing techniques and used OpenCV and Pandas as part of the broader workflow. The resulting particle-tracking system transformed image sequences into structured observations for the proposed control scheme.

## Project delivery

Alongside the technical work, I used a Gantt chart to manage resources and timing and maintained project reports in LaTeX. That combination kept the experimental, software, and documentation work aligned across the project timeline.
