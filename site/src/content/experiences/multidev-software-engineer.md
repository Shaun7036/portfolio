## Scope

At Multidev Technologies, I worked across application development, infrastructure, integrations, and data reliability for a multi-carrier shipping platform. The platform connected Canada Post, FedEx, UPS, and USPS services and supported thousands of shipments each month.

## Platform and integrations

I delivered RESTful services and responsive interfaces using Laravel, Vue.js, MySQL, and Inertia. I also developed reusable carrier integrations, including a Composer-packaged UPS PHP library and a FedEx REST API wrapper, with deployment pipelines for controlled package delivery.

## Infrastructure and delivery

I migrated containerized workloads from Google Cloud Docker Swarm to AWS Lightsail and implemented CI/CD with GitHub Actions. The new workflow reduced deployment time from hours to minutes and increased release frequency by three times.

I also built a package-management application for microservices and binaries using Chocolatey and ProGet, automating remote provisioning through PowerShell and APIs.

## Data reliability and performance

I architected event-driven ingestion pipelines with Laravel observers, Redis queues, and SMTP alerts to synchronize MySQL with client InterBase databases. This improved data reliability and reduced manual reconciliation by 90%.

For shipping queries, I implemented asynchronous background processing and caching that reduced API latency and improved workflow performance by 70%.
