## Scope

I developed shipping software, carrier integrations, and data infrastructure at Multidev Technologies. The platform connected Canada Post, FedEx, UPS, and USPS and supported thousands of monthly shipments.

## Platform and integrations

I built RESTful services and interfaces with Laravel, Vue.js, MySQL, and Inertia, plus a Composer-packaged UPS library and a FedEx REST API wrapper.

## Infrastructure and delivery

I migrated containerized workloads from Google Cloud Docker Swarm to AWS Lightsail and automated CI/CD with GitHub Actions. Deployment time fell from hours to minutes, and release frequency tripled.

I also built a package manager with Chocolatey and ProGet, automating remote provisioning with PowerShell and APIs.

## Data reliability and performance

Event-driven pipelines using Laravel observers, Redis queues, and SMTP alerts synchronized MySQL with client InterBase databases, reducing manual reconciliation by 90%.

Asynchronous processing and caching improved shipping workflow performance by 70%.

## Systems integration and observability

I connected CRM and POS workflows to reduce duplicate entry and deployed Grafana, Loki, and Alloy for centralized log analysis.
